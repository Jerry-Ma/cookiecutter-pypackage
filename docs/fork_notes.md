# Fork Notes

**Fork:** [Jerry-Ma/cookiecutter-pypackage](https://github.com/Jerry-Ma/cookiecutter-pypackage), branch `v2026`
**Based on:** [audreyfeldroy/cookiecutter-pypackage](https://github.com/audreyfeldroy/cookiecutter-pypackage) `main`

This fork adapts the template for scientific Python / Astropy-ecosystem projects. The original docs are preserved as-is for reference. Key divergences from the original:

- **Sphinx** (sphinx-astropy theme) replaces Zensical/MkDocs for documentation; deploy with `just doc-deploy` (ghp-import), not a GitHub Action
- **BSD-3-Clause** replaces MIT as the generated project license
- **setuptools + setuptools_scm** replaces hatchling; version is SCM-derived, not a static `first_version` prompt
- **Python 3.13+** required (original: 3.12+)
- **8 prompts** instead of 10 — `author_website` and `first_version` removed
- **Pre-commit hooks** included and wired via `just install` (design_decisions.md says otherwise — that section is from the original); the hook entry-point lives in `.githooks/pre-commit` (tracked in git) and delegates via `uv run pre-commit`, making it portable across Docker bind-mounts without reinstalling
- **No GitHub Actions workflows** generated by default — add them per-project as needed
- Project structure: `cli/__init__.py` package (not flat `cli.py`); no `utils.py`, `CHANGELOG/`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `ISSUE_TEMPLATE.md`
